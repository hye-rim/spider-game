# 스파이더 카드 🕷️

윈도우에 기본으로 들어 있던 스파이더 솔리테어. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)입니다.

- 카드 104장(2벌)을 10열에 깔고, **같은 무늬로 K→A 13장**을 이어 붙이면 사라진다. 8묶음을 없애면 승리
- 난이도 세 가지: **1무늬**(♠ 8벌) · **2무늬**(♠♥) · **4무늬**(♠♥♣♦)
- 옮기는 법: 같은 무늬로 1씩 줄어드는 묶음을 통째로 옮긴다. 놓을 곳은 '한 끗 큰 카드 위'(무늬 상관없음)나 빈 열
- 더미(왼쪽 아래)를 누르면 열마다 한 장씩 나눠 준다 (빈 열이 없을 때만, 5번)
- 카드를 **누르면 알아서 가장 좋은 열로 옮기고**, **끌어서 놓을** 수도 있다
- 점수: 500점에서 시작, 옮길 때마다 -1, 한 묶음 완성마다 +100, 승리하면 시간 보너스
- 되돌리기(무제한, 한 번에 -1점) · 💡 힌트 · 이어하기(브라우저에 자동 저장)
- 최고 기록: `spiderBest1` · `spiderBest2` · `spiderBest4`, 로비용 `spiderBest`(셋 중 최고)

판 규칙은 `logic.js`(화면 없이 Node 로도 돌려 볼 수 있다), 화면·입력은 `game.js`.
